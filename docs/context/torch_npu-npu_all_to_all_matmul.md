## 功能说明

- API功能：完成AlltoAll通信、Permute(保证通信后地址连续)和Matmul计算的融合，**先通信后计算**。
- 计算公式:
  假设x1输入shape为(BS, H)
  $$
  commOut = AlltoAll(x1.view(rankSize, BS/rankSize, H)) \\
  permutedOut = commOut.permute(1, 0, 2).view(BS/rankSize, rankSize*H) \\
  output = permutedOut @ x2 + bias \\
  $$

## 函数原型

```
torch_npu.npu_all_to_all_matmul(Tensor x1, Tensor x2, str hcom, int world_size, Tensor? bias=None, int[]? all2all_axes=None, bool all2all_out_flag=True) -> Tensor
```

## 返回值说明
`Tensor`

代表`npu_all_to_all_matmul`的计算结果，对应公式中的output，假设x1的shape为(BS,H)，x2的shape为(H*rankSize,N)，则output的shape为(BS/rankSize,H*rankSize)。输出output的数据类型和x1一致。

## 约束说明
* 默认支持确定性计算
* 参数说明中shape使用的变量BS必须整除rankSize
* x1、x2的数据类型必须一致
* bias的数据类型可以为x1 x2的数据类型，也可以为float32
* 通算融合算子不支持并发调用，不同的通算融合算子也不支持并发调用。
* 不支持跨超节点通信，只支持超节点内。
