# npu_gelu_mul Operator Integration Summary

**Date**: 2026-07-25
**Operator Name**: aclnnGeluMul
**torch_npu Function Name**: npu_gelu_mul

## 1. Operator Functionality

将输入 Tensor 按最后一个维度切分为左右两部分 `x1`（前半）与 `x2`（后半），对 `x1` 做 GELU 激活后再与 `x2` 逐元素相乘。输出 shape 在其他维度上与输入一致，最后一维 = 输入最后一维的 1/2，输出 dtype == 输入 dtype。

$$x_1=\text{input}[\dots,:d],\quad x_2=\text{input}[\dots,d:],\quad \text{out}=\text{GELU}(x_1)\times x_2$$

支持 dtype：BFLOAT16 / FLOAT16 / FLOAT；维度 2–8；最后一维为偶数且 ≤1024；其他维度乘积 ≤200000；支持空 Tensor。支持芯片：Ascend 950PR/950DT (A5)、Atlas A3、Atlas A2 (910B)。

## 3. Key Technical Points

- **输出 shape 非恒等**：末维减半，是本算子的核心难点；C++ 复用既有 `npu_gelu_mul_output_size` helper，meta 逐行镜像，二者作为图模式 shape 推断的「参照实现」必须一致（否则图模式静默错误）。
- **手动 opapi 路线**：与 npu_gelu（gen_opapi 自动生成）不同，本算子采用手动 cpp + `op_api:` 注册，便于落地全部 TORCH_CHECK 约束。
- **ErrCode 枚举**：仓库 ErrCode 无 DIM 成员；维度/数值类校验统一用 `ErrCode::VALUE`（C++）与 `ErrCode.VALUE`（Python）。
- **char* 传参**：`approximate` 经 `const_cast<char*>(str.data())` 以 lvalue 传入 EXEC_NPU_CMD（满足宏的左值引用绑定）。
