## 1. 算子功能

SwiGlu 激活 + 量化融合算子（MoE / 非 MoE 场景通用）。将输入 `x` 末维二分为 a、b 两半，做 SwiGlu 激活后按 smooth_scales 缩放，再做静态或动态量化，输出量化张量 `y`（INT8/INT4）与量化系数 `scale`（FLOAT）。

- **SwiGlu**：`activate_left=False`（默认）→ `y_pre = a * silu(b)`（silu 作用于右半）；`activate_left=True` → `silu(a) * b`。a=x 末维前半，b=后半。
- **动态量化** `quant_mode="dynamic"`：`scale = qmax / row_max`（qmax = 127(int8) / 7(int4)），`y = round(y_pre * scale)`。
- **静态量化** `quant_mode="static"`：`y = round(y_pre * smooth_scales + offsets)`，`scale` 输出恒为全 0。
- **MoE 分组**：`group_index` + `group_list_type`（0=cumsum 累计边界 / 1=count 计数）决定每行所属分组，按组索引 smooth_scales/offsets。
- **输出 dtype**：`dst_type`=2→INT8，29→INT4（ge::DataType 约定）。

## 3. 关键技术点

- **dst_type acl dtype 映射**：ge::DataType 与 aclDataType 数值对齐（INT8=2/INT4=29），必须 `static_cast<aclDataType>`，禁用 `c10_npu::GetAclDataType`（会按 aten ScalarType ordinal 误解 2→Short→INT16）。
- **INT4 输出**：以 `at::ScalarType::Byte` 分配张量，经 `TensorWrapper` 携带真实 acl dtype（INT4）传给内核。
- **可选张量**：缺省 optional 经 `c10::value_or_else` 转未定义 `at::Tensor()`，aclnn 侧对应 null aclTensor*。
- **dtype 前置校验**：置于 `EXEC_NPU_CMD` 前，防止非法 dtype 触发 aclnn 同步报错（107000）后遗留错误态污染后续调用。
- **内核运行约束（记入 memory `swiglu-quant-kernel-semantics`）**：smooth_scales 实测必需；SwiGlu 默认 silu 作用右半；静态量化 scale 恒 0。
